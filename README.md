# Raw Clipboard (极简纯内存剪贴板管理器)

一个支持 GNOME Shell 51+ 的纯 GJS、零外部依赖、长青接口的极简剪贴板历史扩展。

## 设计特性
1. **零外部依赖 (Pure GJS)**：
   - 不依赖 `libgda`、SQLite、GSound 或任何外部后台守护进程，仅使用 GNOME 标准库（`Gio`、`GLib`、`St`、`Meta`、`Clutter`）。
2. **Raw 核心数据透传 (等价操作)**：
   - 捕获阶段：智能嗅探核心 MIME 类型（图片 `image/png`、文件列表 `text/uri-list`、纯文本 `text/plain`、富文本 `text/html` 等），直接保存无损原始字节流。
   - 回放阶段：原样调用 `St.Clipboard.set_content(..., mime, bytes)` 注入系统剪贴板，使粘贴行为与复制时完全等价。
3. **多类型与单类型统一架构 (Multi-type & Single-type Unified Engine)**：
   - **真实场景支持**：现代网页浏览器（Chrome、Firefox、Edge 等）及办公套件在用户复制加粗、带链接或排版的富文本时，剪贴板源会同时发出 `text/html` 与 `text/plain;charset=utf-8` 等多重表示供目标程序协商自选；
   - **统一数据模型 (Entry Formats)**：彻底统一多类型与单类型，类型作为记录（Entry）的属性（`formats: [{ mime, type, icon, label }]`），单类型包含 1 项格式，多类型包含 2 项或多项格式，不再按 MIME 分裂根；
   - **纯内存容器打包 (CMP1)**：无损捕获多格式双流数据，通过自包含纯二进制格式封装（零磁盘落地、零外部进程），在保持 raw 字节纯度的同时实现双格式完整暂存；
   - **全局统一前缀树与存储利用率提升**：`RadixRawTree` 采用全局统一树根，所有类型二进制流统一进行查重与公共前缀共享，跨类型复用公共前缀节点，存储空间利用率大幅提升；
   - **左侧 48x48 扁平化正方形类型按钮 (按需选择回灌)**：条目左侧仿照删除按钮的扁平化正方形设计（48x48 点击热区），多类型条目并排显示富文本与纯文本两个 48x48 正方形按钮：
     - 点击富文本图标：直接以 `text/html` 格式回灌，完美保留富文本排版与格式；
     - 点击纯文本图标：直接换用纯文本类型标签回灌，轻松绕过目标程序（如终端、部分代码编辑器）不收 HTML 的类型门禁；
     - 点击条目主体文本或按回车：按首选默认格式原样回灌；
   - **未知类型原样保留与标签展示**：对 SVG、Office 专有格式或系统自定义未知类型，统一作为 raw 二进制流无损保留，在预览区原样展示其 MIME 类型标签字符串帮助识别判断，并与文本类记录一视同仁支持检索与复制文本；
   - **右键“复制文本” (原样进出原则)**：右键菜单提供“带入搜索”与“复制文本”两大功能。坚持原样进出原则，不再对内容进行破坏性解析修改，而是直接换用纯文本类型标签注入系统剪贴板，并在历史队首新增一条纯文本记录（对富文本、文件列表、未知类型等所有以文本形式预览的条目开放）。
4. **字节级全局前缀复用存储 (RadixRawTree)**：
   - 存储即查重，查重即存储。使用纯内存 Radix Raw 前缀树进行高密度复用存储，所有单类型与多类型数据共享同一棵前缀树，公共前缀物理内存切片共享，后缀自动分叉，条目删除时沿树向上剪枝收缩，超限自动 FIFO 级联淘汰。
5. **纯进程内存存储 (重启即清空)**：
   - 数据完全保留在 GNOME Shell 进程内存中，不写入磁盘，关机或注销时随进程退出自动销毁，保护隐私。
6. **快捷交互 (Super+V 鼠标指针浮动)**：
   - 默认通过 `Super+V` 唤出，窗口锚定在鼠标指针附近，带屏幕边缘防溢出处理；
   - 每页严格展示 8 项并显示底部居中页码；支持循环翻页并具备防误触保护，在第一页向上翻页或末页向下翻页时，首次操作不翻页并在页码左侧提示“循环？”（英文下为“Loop? ”），第二次同向操作才执行跨页并恢复正常页码；
   - **触控板单次划动锁步与滚轮防抖**：
     - **触控板手势算法优化**：双指轻划锁步（One Swipe = Exactly One Page），彻底杜绝触控板失控连翻；抬手或静止 180ms 即刻开启下一手势，滑动中反向划动即刻解锁响应；
     - **机械滚轮防抖**：带齿物理鼠标滚轮一格一页，带 60ms 极速平滑防抖；
   - 弹窗顶部提供 4 种排序方式（记录顺序、大小、类型、首字母 / Order, Size, Type, A-Z），支持鼠标点击顶栏胶囊按钮或按 `Tab`/`Shift+Tab` 键循环切换：
     - **记录顺序**：按条目复制时间排序，最新入队或重复复制项排在队首；
     - **大小**：按数据容量字节大小由大到小降序排列；
     - **类型**：按内容类型分组优先排列（文本优先，其次为复合/多类型、网页、文件、位图及未知类型）；
     - **首字母**：英文条目按 A-Z 优先排列，非英文字符与其它语言排在英文后面并按记录顺序排列；
   - **键盘条目身份强绑定 (消灭并发错配)**：键盘回车恢复、空格注入及 Delete / Backspace 删除操作，严格绑定到屏幕当前可见选中的条目身份，绝不在待重绘期间重新用排序索引取目标，彻底杜绝后台插入新剪贴板时的竞态误操作；
   - **独立多语言切换 (不读取系统语言环境)**：弹窗支持中文与英文双语切换（默认中文），完全由独立的 GSettings 配置项驱动，**绝不探测或读取宿主机系统的 locale 与 `LANG` 环境变量**；排序栏、撤销操作、循环提示（“循环？ ” / “Loop? ”）、条目类型与时间、搜索提示及空状态文本全面本地化，配置变更时在位热切换，零闪烁、无须重启；
   - **预览内搜索 (Search Previews)**：在弹窗中直接键入任意字符，自动唤起搜索栏替代排序选项卡，实时匹配文本、富文本、文件列表及未知类型的预览文本，搜索结果以记录顺序排序并支持循环翻页（同享首末页二次防误触保护）；采用纯键盘直接驱动架构，彻底禁用输入法（IME），从根源杜绝 GNOME Shell 模态层遮挡输入法候选框及首字母遗漏的经典缺陷；搜索框设 128 字符上限防止内存膨胀，占位文字采用独立灰度提示色；输入时按 `↑`/`↓` 可直接在结果列表中选择条目，按 `Enter` 确认恢复；鼠标点击搜索栏自身、弹窗外任意区域及非条目空白区域，或按 `Esc` 键均可退出搜索状态回到完整列表；删光字符时显示“无匹配项目”；
   - 列表采用槽位复用 (Slot Pool) 与在位更新架构，彻底杜绝材质销毁重建闪烁；
   - 每个条目右侧实时记录并展示复制时间（当天精确展示时分秒，跨天展示 `n天前 时分` 或 `nd ago 时分`），重复复制相同内容时自动更新复制时间并提升至队首；
   - 支持全键盘操作：`↑`/`↓` 步进（首尾跨页防误触）、`←`/`→` 或 `PgUp`/`PgDn` 翻页（首末循环二次确认防误触）、`Tab`/`Shift+Tab` 切换排序、`Enter`/`Space` 恢复、`Delete`/`Backspace` 删除当前条目、`Ctrl+Z` 撤销删除、`Esc` 退出（优先关闭右键菜单或搜索状态）；
   - 支持鼠标操作：悬停高亮、触控板手势与滚轮翻页（首末循环二次操作防误触）、左键点击条目恢复、点击 48x48 扁平正方形垃圾桶按钮删除条目；
   - **右键上下文菜单 (Context Menu)**：在任意历史条目上点击鼠标右键弹出操作菜单：
     - **带入搜索 (Search Preview)**：将该条目预览内容的前 64 字符带入搜索框并覆盖已有内容执行即时检索（搜索状态下亦可在检索结果中右键带入）；
     - **复制文本 (Copy Text)**：对所有以文本形式预览的条目（富文本、文件列表、未知类型等）开放，遵循“原样进出”原则直接换用纯文本类型标签回灌系统剪贴板，并在队首新增一条纯文本记录；
     - 右键菜单具备屏幕边界防溢出保护，按 `Esc` 键或点击弹窗内外部任意空白处优先关闭菜单而不影响弹窗。
7. **双语设置界面规范 (Libadwaita)**：
   - 中英双语直观对照界面；
   - 界面语言切换按钮（`中文` | `English` 互斥联动，默认中文，与系统环境变量完全解耦）；
   - 快捷键录制、最大历史记录限制 (5 ~ 1000 项)、单项记录容量限制 (5 ~ 1024 MB)、所有记录容量限制 (50 ~ 4096 MB)、图片预览最大尺寸限制 (512 ~ 16384 像素)；
   - 超时保护（传输停滞超时、总体传输超时）；
   - 诊断日志开关（默认静默）。
8. **接口长青 (Stable & Evergreen)**：
   - 避开易变复杂的 QuickSettings 树，使用底层稳定的 St.Widget 浮动挂载，跨版本兼容性强。

## 安全边界与已知取舍

### 本扩展保证什么
- **不落盘**：整个代码库不含文件写入、数据库、守护进程、网络或子进程调用；剪贴板内容只存在于 GNOME Shell 进程内存中。
- **随进程销毁**：注销、重启或禁用扩展即释放——`disable()` 会取消在途读取并清空内存历史与存储树。
- **日志不含内容**：诊断日志默认关闭；开启后也仅记录条目 ID、预览文本 MD5 前 8 位指纹（不可预览类型不输出 MD5）、类型、MIME、大小等元数据，**不记录剪贴板内容明文**。
- **不读文件内容**：复制文件/目录时只保存路径字符串，不读取文件数据；剪切文件（Ctrl+X）条目不入库（专注于 GNOME 原生文件管理器 Nautilus，精准识别普通复制并放行入库，拦截真实剪切）。
- **锁屏不弹窗**：快捷键注册于 `NORMAL | OVERVIEW | POPUP`，锁屏与系统认证对话框下不会弹出历史窗口。

### 本扩展不保证什么（请按你的威胁模型评估）
- **不过滤敏感内容**：为了可用性，本扩展不按 `x-kde-passwordManagerHint` 等标记过滤，口令、令牌会照常进入历史，并**在弹窗中以明文显示预览**（最长 1000 字符）。如果不接受这一点，请不要使用本扩展。
- **不隔离同进程的其它扩展**：GNOME Shell 的所有扩展共享同一个 JS 运行时，平台不提供扩展间隔离；任何已安装扩展都能访问本扩展实例与其内存中的历史。这是平台限制，不是本扩展可控项。
- **不防"看得见屏幕的人"**：内容以明文渲染在弹窗中，任何能看屏、录屏或（启用无障碍总线时）读取无障碍树的程序都能获得它。无障碍默认未启用。
- **不阻止锁屏期间继续捕获**：为满足"锁屏前后不丢内容"，本扩展声明了 `unlock-dialog` 会话模式，锁屏时仍会捕获剪贴板，只是不弹出窗口。

### 扩展无法覆盖的系统层通道
- 进程内存可被换出到 swap；Shell 崩溃时可能由 `systemd-coredump` 落盘；同用户进程在 `kernel.yama.ptrace_scope=0` 时可直接读取进程内存。
- 需要这些防护时请在系统层加固：加密 swap/zram、`/etc/systemd/coredump.conf` 设 `Storage=none`。
- 若开启诊断日志，日志会进入 systemd journal（多数发行版落盘）——这是本扩展唯一可能主动产生落盘的路径（仅含元数据与 MD5 指纹，无明文内容），默认关闭。

### 容量语义
- 单条上限（默认 50 MB）与总量上限（默认 1024 MB）为**近似值**：内存储存采用字节级前缀复用，实际驻留通常低于所设上限。
- **超出上限淘汰**：当总容量超出总量上限时，按 FIFO 淘汰最旧条目；若单项数据大小超过所设总量上限，该条目在总量上限检查中会被淘汰。

## 安装

```bash
gnome-extensions install --force raw-clipboard@local.shell-extension.zip
gnome-extensions enable raw-clipboard@local
```
